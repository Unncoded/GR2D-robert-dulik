# Gra typu top-down polegająca na walce mieczem i unikach
Sterowanie:
- WSAD służy do poruszania się
- Strzałki służą do ataku mieczem
- Spacja służy do przeskakiwania nad ciemnoszarymi powierzchniami (w zamyśle przepaści)

Przeciwnicy podświetlają się na chwilę przed strzałem, dając czas na reakcję.

Gra obsługuje lokalną tablicę wyników, mierząc czas i zgony gracza.
